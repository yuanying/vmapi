# 0007. HTTP API の契約を OpenAPI で一つに決める

- Date: 2026-10-30
- Status: Accepted

## Context

vmapi の API は、`vmctl`、画面、dotfiles の pi extension（codemode の道具）、その先の Penelope の宣言したツールから呼ばれる（[[0001]]）。pi extension は vmapi の実装と並行して作るので、実装より先に契約が要る。

codemode のスクリプトは応答を JSON として受け取り、フィールドで絞り込む。呼ぶ側はエージェントが多く、応答の形が変わったときに人間ほど柔軟には対応しない。

## Decision

**API の契約は `api/openapi.yaml`（OpenAPI 3.1）に書き、実装も呼ぶ側もこれに合わせる。** 契約を変えるときは、先にこのファイルを変える。

### 形

- パスは `/api/v1/` の下に置く。`/` は画面に使う。
- リソースは VM（`/api/v1/vms/{name}`）、そのスナップショット（`/api/v1/vms/{name}/snapshots/{snapshot}`）、イメージ（`/api/v1/images`）、利用者自身（`/api/v1/whoami`）である。
- VM とスナップショットは名前で指す。名前は全体で一意である（[[0003]]）。
- 状態を変える操作（起動・停止・復元）は、リソースの下の `POST`（`/start`・`/stop`・`/revert`）にする。

### 将来の追加で壊れない形

- **応答はいつも JSON のオブジェクトにする。** 一覧も配列をそのまま返さず、`{"vms": [...]}` のようにオブジェクトに包む。ページ送りなどのフィールドを後から足せるようにするためである。
- **応答には後からフィールドが増える。** 呼ぶ側は知らないフィールドを無視する。
- **状態やエラーの種類のような文字列の値は、後から増える。** OpenAPI では `enum` にせず、今ある値を説明に挙げる。呼ぶ側は知らない値を「その他」として扱う。
- **リクエストの知らないフィールドは `400` で拒否する。** `memory` と `memory_mib` の書き間違いのような誤りを、黙って既定値で通さないためである。
- 量には単位を名前に含める（`memory_mib`・`disk_gib`）。フィールド名は snake_case にする。日時は RFC 3339 の文字列にする。

### エラーの形

**エラーはすべて同じ形にする。** 本文は `error` という一つのフィールドを持つオブジェクトで、その中に機械が読む `code` と、人間が読む `message` を持つ。呼ぶ側は `code` で分岐し、`message` の文言には頼らない。

| code | HTTP | 意味 |
|---|---|---|
| `invalid_argument` | 400 | リクエストの形や値が誤っている |
| `unauthenticated` | 401 | `X-Devbox-User` が無い（[[0002]]） |
| `permission_denied` | 403 | 管理者でない利用者が他人の持ち主で絞り込んだ |
| `not_found` | 404 | VM・スナップショット・イメージが無い、または自分のものでない |
| `already_exists` | 409 | 同じ名前の VM・スナップショットがある |
| `ip_in_use` | 409 | 指定した IP を他の VM が使っている |
| `ip_exhausted` | 409 | 払い出せる IP が残っていない |
| `unavailable` | 503 | libvirt に届かない、イメージを取得できないなど、時間をおけば直りうる |
| `internal` | 500 | それ以外 |

### 同期と非同期

- 作成は同期とし、define と start が済んだら `201` で VM を返す（[[0001]]）。
- 強制でない停止は、ゲストに ACPI のシャットダウンを送るだけで、止まるのを待たない。`202` で VM を返し、呼ぶ側は取得を繰り返して止まったことを確かめる。強制の停止はすぐに止めて `200` を返す。
- 起動と停止は、すでにその状態であっても成功を返す。呼ぶ側が「今どうなっているか」を先に調べなくてよいようにするためである。
- 削除は、動いている VM なら強制的に止めてから消し、`204` を返す。

## Consequences

- pi extension と `api-server` の実装は、`api/openapi.yaml` だけを見て並行して進められる。
- 応答の形を変えずにフィールドを足すのは自由だが、フィールドの意味を変える・消すのは `/api/v2/` を作るときに限られる。
- 状態やエラーの値を `enum` にしないので、OpenAPI からコードを生成しても値の網羅は検査されない。そのぶん、値を足しても呼ぶ側の生成コードが壊れない。
- 強制でない停止は、ゲストが ACPI に応じなければいつまでも止まらない。呼ぶ側は待つ時間を決め、過ぎたら強制の停止を使う。
